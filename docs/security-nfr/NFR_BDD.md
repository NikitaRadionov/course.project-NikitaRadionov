
# NFR BDD Scenarios

## 1. NFR-01: Безопасность хранения паролей
**Scenario: Пользовательский пароль хэшируется безопасно**
Given новый пользователь с паролем "Secret123"
When пользователь регистрируется в системе
Then пароль должен быть сохранен с использованием алгоритма Argon2id

## 2. NFR-03: Производительность `/media`
**Scenario: Среднее время отклика при запросе медиа**
Given 50 запросов в секунду к media
When выполняется выборка списка медиа
Then p95 время отклика должно быть < 500 мс

## 3. NFR-04: JWT безопасность
**Scenario: Срок действия токена доступа**
Given пользователь получил JWT токен
When проходит 30 минут
Then токен становится недействительным

## 4. NFR-05: Обработка недействительных токенов
**Scenario: Запрос с неверным токеном**
Given пользователь делает запрос с недействительным JWT
When сервер получает запрос
Then возвращается HTTP 401

## 5. NFR-08: Резервное копирование БД
**Scenario: Ежедневное резервное копирование**
Given ежедневная задача резервного копирования
When выполняется скрипт резервного копирования
Then должен создаваться хотя бы один бэкап за сутки
And бэкапы должны храниться не менее 30 дней

## Негативные сценарии

### Scenario: Попытка регистрации без пароля
Given пользователь пытается зарегистрироваться без указания пароля
When сервер обрабатывает запрос
Then возвращается ошибка HTTP 400 с сообщением о недопустимом пароле

### Scenario: API недоступен
Given сервер Media Catalog не отвечает на `/media/`
When пользователь делает запрос
Then система должна вернуть ошибку 503 и логировать инцидент
